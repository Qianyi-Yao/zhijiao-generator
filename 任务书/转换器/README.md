# 图书馆转换器

转换器支持将单个 `.pptx` 正篇或 `.md` 番外文件拖到 `运行.bat` 导入。

首次使用或更新 Python 环境时，在本目录运行：

```powershell
python -m pip install -r requirements.txt
```

Markdown 图片路径以 Markdown 文件所在目录为基准。番外按 H4 标题分篇，只导入以“关于”开头的条目；人物标签写在标题末尾的方括号中。日期周范围使用 H2/H3 标题，格式为 `2026.5.24~2026.5.30`、`2026.9.13~9.19` 或 `8.9~8.15`。省略年份沿用前置日期标题的明确年份；未出现明确年份时使用转换器中的 `YEAR`。
