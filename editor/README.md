# 本地图书馆编辑器

双击 `启动编辑器.bat`，会在系统默认浏览器中打开编辑器，沿用该浏览器原有用户配置和下载目录，不再创建临时 Edge 配置。运行栏可能短暂闪现，随后隐藏。需要 Python 3.10 或更新版本，日常写作无需联网或运行 npm。

联动退出仍然保留：关闭本次会话最后一个主编辑器页面后，等待约 5 秒确认没有刷新重连，再关闭通过编辑器链接打开的图书馆预览页并退出本地服务；已接受的保存、发布请求会处理完成。其他日常浏览器页面及另外启动的编辑器不受影响。刷新、最小化、单独关闭预览、取消未保存内容的关闭提示都不会结束会话。关闭前仍须确认草稿已保存。

请直接点击编辑器中的图书馆链接打开预览（也支持 Ctrl 点击和鼠标中键）。右键菜单打开或手动粘贴地址产生的页面可能受浏览器限制，无法自动关闭，需要手动关闭。仅在页面明确通知离开后启动联动退出计时；后台连接中断或切换标签页不会触发退出。浏览器被强制结束或关闭通知未送达时，服务可能残留，需要另行结束。

草稿仍保存在 `library/editor-drafts/`，运行日志位于 `%LOCALAPPDATA%\ZhijiaoGenerator\logs`。开发调试用的 `python editor/server.py` 保留运行栏，需按 `Ctrl+C` 手动退出；正常使用请双击 BAT。

左侧默认只显示本周的编辑器篇目；点击日历中的任一天，会筛选该天所在周（日到六）的草稿和已发布篇目。“回到本周”可清除历史周筛选。切换周次不会关闭右侧正在编辑的篇目。“新建篇目”会创建在左侧日历当前选中的周，不会跳回本周；例如先选上一周的任意一天，再点新建即可补写上一期。未切换日期时默认创建在本周；如需调整所属期，也可在篇目正文上方修改日期。无日期的奇遇草稿收在独立的“奇遇”入口中。列表过长时可在左侧列表内滚动。

文章预览下方是人物标签积分卡片，统计网页图书馆中所有已发布篇目，不计未发布草稿。正篇每个人物 tag 得 10 分，番外和奇遇得 1 分；朝代榜将人物分数按人物资料中的朝代累加。默认显示前 10 名，可展开查看完整榜单。点击“统计时间”可在日历上先后选择起始日和结束日；只选一天时可选择“从这天起”或“截至这天”，点击“清除”回到全时间。起止日期均包含在内，只要篇目日期范围与筛选范围相交就计入。无日期的奇遇只计入全时间榜。日期选择器复用项目内的离线 flatpickr 组件。卡片在启动、成功发布和点击“重新读取图书馆”后更新，不会定时联网。人物姓名与 tag 使用“姜子牙／庄周／墨翟”，输入旧称时保存会自动规范为这些姓名。

人物榜的人名右侧显示实装日期，数据表在 `library/data/character_release_dates.json`。表内按截图分为天／地／玄三组，该分组仅用于核对截图，不覆盖 `characters.js` 的现有品阶；日期用 `YYYY-MM-DD`。截图中的“开服”统一记作 `2020-03-19`。谢安实装日期记为 `2026-10-22`；大小乔各自只记录 `2021-04-30`，不处理截图中的“天”标记。截图未收录的人物显示“待补”。修改数据表后点击编辑器顶部“重新读取图书馆”即可刷新显示；朝代榜仍只展示朝代及积分。

积分卡片下方有“奇遇人物关系”入口，显示名士数、已有关系数和已发布奇遇篇数。展开后，编辑器抽选名单中的全部名士以头像显示：有关系的人物居中，没有关系的人物排在外围。已发布奇遇才会生成连线；同一对人物的多篇奇遇合并为一条线。可拖动、缩放、搜索姓名或重置视图；点击头像会突出其关系，点击连线可查看两人的奇遇，并在新标签页打开网页图书馆篇目。关系图在启动、成功发布和点击“重新读取图书馆”后更新，不受积分榜日期筛选影响。绘图库已经打包在离线编辑器中，日常使用无需联网。

正文上方和下方都有相同的工具栏，按“文字”“段落”“插入”“操作”分组；“插入”里可以选择本地图片、左图右文图文段、表格或篇目链接。插入表格时填写行列数，光标进入表格后会显示增删行列、合并和拆分等操作。左图右文块可放多张图片、调整顺序，并在右侧直接写字或插入表格；点击独立图片可以转换成图文段，图文段也可转换回独立图片和文字。图片只通过本地文件选择器加入。篇目跳转需先选中文字，再打开“插入 → 篇目链接”，输入篇名关键词或日期；用 ↑↓ 选择搜索结果、回车设置链接，也可点击结果和按钮。点击搜索框外或按 Esc 可关闭。草稿会自动保存，也可以点击“保存草稿”。

字色和背景色可直接输入十六进制颜色（如 `#2E6A67` 或 `fff`），输入框左侧会预览当前颜色；输入本身不会改动正文。先选中文字，再点击对应的“应用字色”或“应用背景色”按钮。每次打开编辑器时，字色输入框默认是 `#2E6A67`。

在新段落行首输入 `> ` 可进入带左侧提示条的引用块，左图右文的右侧文字也支持；在引用中按回车继续写下一段，再在空段落按回车退出。引用内默认使用正文字体，也可选中文字后用“引文楷体”或“正文字体”单独调整。

公式独占一行：输入 `$$` 后按回车，接着输入 LaTeX 源码；公式下方会即时显示排版效果。写完后另起一行输入 `$$` 并按回车，即可回到普通段落。草稿保留源码，网页图书馆与长图使用本地打包的 KaTeX 渲染，无需联网。

“发布这篇到网页图书馆”会逐篇更新 `library/data/library.json` 和所需图片，并在 `library/editor-backups/` 留下发布前的数据备份。草稿及其原始图片存于 `library/editor-drafts/`；这两个目录不会加入 Git。发布后可重新打开同一草稿修改并再次发布，文章 ID 不变。已有 PPT 文章只可作为跳转目标，不能在此编辑。网页图书馆的分享长图仍在 `library.html` 中生成。

编辑器启动和每次成功发布后，会清理已保存超过 30 天、且仍保持原样的编辑器自动备份。草稿、草稿图片和其他备份目录不会被清理。

误建的未发布草稿可以在编辑器里删除；已发布文章的草稿保留，以便继续修改原文章。

如果图书馆数据在编辑期间发生变化，发布会停止并提示重新读取。请先核对本篇与图书馆数据，再点顶部“重新读取图书馆”。编辑器写的文章带 `origin: "editor"`，PPT 转换器重转同一期时会保留它们。

开发者修改 `src/library-editor.js` 或 `src/relationship-graph.js` 后运行 `npm install`、`npm run build:editor`，更新离线脚本 `editor/bundle.js`。编辑器使用 Tiptap / ProseMirror 与 Cytoscape.js 开源组件，许可文本在本目录。

编辑器内按 Ctrl+S（或 Command+S）会执行“保存草稿”，不再弹出浏览器的另存网页对话框。


### 奇遇管理
左栏和预览区的“奇遇管理”打开同一个窗口。左侧关系图支持拖动、缩放及查找人物，右侧列表可按篇名、人物和发布状态搜索。点头像筛选该人物，点连线筛选该配对；实线表示已有发布篇目，虚线表示只有未发布草稿。未选齐人物的草稿保留在列表中。
顶部可新建空白奇遇，选中人物或配对后可预填人物新建。点击“编辑”回到正文编辑区；已发布篇目还可在图书馆查看。本机无草稿的篇目只提供查看。重新打开窗口会保留筛选和图的浏览位置。
