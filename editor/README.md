# 本地图书馆编辑器

双击 `启动编辑器.bat`。它会在本机启动一个临时网页服务并打开浏览器；编辑时保持命令窗口开启，结束后按 `Ctrl+C` 关闭。需要 Python 3.10 或更新版本。日常写作不需要联网，也不需要运行 npm。

先在左侧选择日期并新建篇目。日期会归到当周周日；同一期可以有多篇文章。正文上方和下方都有相同的工具栏，按“文字”“段落”“插入”“操作”分组；“插入”里可以选择本地图片、左图右文图文段、表格或篇目链接。插入表格时填写行列数，光标进入表格后会显示增删行列、合并和拆分等操作。左图右文块可放多张图片、调整顺序，并在右侧直接写字；点击独立图片可以转换成图文段，图文段也可转换回独立图片和文字。图片只通过本地文件选择器加入。篇目跳转需先选中文字，再打开“插入 → 篇目链接”，输入篇名关键词或日期、从结果中选择目标文章并设置链接。草稿会自动保存，也可以点击“保存草稿”。

字色和背景色可直接输入十六进制颜色（如 `#1c1e23` 或 `fff`）；输入本身不会改动正文。先选中文字，再点击对应的“应用字色”或“应用背景色”按钮。

在新段落行首输入 `> ` 可进入带左侧提示条的引用块，左图右文的右侧文字也支持；在引用中按回车继续写下一段，再在空段落按回车退出。引用内默认使用正文字体，也可选中文字后用“引文楷体”或“正文字体”单独调整。

“发布这篇到网页图书馆”会逐篇更新 `library/data/library.json` 和所需图片，并在 `library/editor-backups/` 留下发布前的数据备份。草稿及其原始图片存于 `library/editor-drafts/`；这两个目录不会加入 Git。发布后可重新打开同一草稿修改并再次发布，文章 ID 不变。已有 PPT 文章只可作为跳转目标，不能在此编辑。网页图书馆的分享长图仍在 `library.html` 中生成。

编辑器启动和每次成功发布后，会清理已保存超过 30 天、且仍保持原样的编辑器自动备份。草稿、草稿图片和其他备份目录不会被清理。

误建的未发布草稿可以在编辑器里删除；已发布文章的草稿保留，以便继续修改原文章。

如果图书馆数据在编辑期间发生变化，发布会停止并提示重新读取。请先核对本篇与图书馆数据，再点顶部“重新读取图书馆”。编辑器写的文章带 `origin: "editor"`，PPT 转换器重转同一期时会保留它们。

开发者修改 `src/library-editor.js` 后运行 `npm install`、`npm run build:editor`，更新离线脚本 `editor/bundle.js`。编辑器使用 Tiptap / ProseMirror 开源组件，许可文本在本目录。
